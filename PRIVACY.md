# Privacy

## English

Dofus Gear Explorer never asks for your Dofus or Ankama account, your password or any personal information. It has no account, no analytics, no tracking and no ads.

- **Everything stays on your computer.** In the desktop app, your stuffs, settings and the downloaded game data are stored in the app's folder. In the web version, your stuffs and settings are stored in the browser, and the game data on the server that runs the API. Nothing is sent to the project's maintainers; there is no project server.
- **Network use.** The app connects to GitHub only, to download the game data published by the [doduda](https://github.com/dofusdude/doduda) project and, for the desktop app, its own updates. Like any download, GitHub receives your IP address; see the [GitHub privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
- **Links.** Links you click (the source code, the licences) open in your browser.

Because the project collects and processes no personal data, there is no data to access, correct or delete on our side. To remove everything, uninstall the app and delete its folder (`~/Library/Application Support/Dofus Gear Explorer` on macOS, `%APPDATA%\Dofus Gear Explorer` on Windows, `~/.config/Dofus Gear Explorer` on Linux).

Anyone who hosts the web version on a server becomes responsible for that server's logs and must publish their own notice.

## Français

Dofus Gear Explorer ne demande jamais votre compte Dofus ou Ankama, votre mot de passe ni aucune information personnelle. Il n'y a ni compte, ni statistiques d'usage, ni pistage, ni publicité.

- **Tout reste sur votre ordinateur.** Dans la version de bureau, vos stuffs, vos réglages et les données du jeu téléchargées sont enregistrés dans le dossier de l'application. Dans la version web, vos stuffs et vos réglages sont enregistrés dans le navigateur, et les données du jeu sur le serveur qui fait tourner l'API. Rien n'est envoyé aux mainteneurs du projet ; le projet n'a pas de serveur.
- **Accès au réseau.** L'application se connecte uniquement à GitHub, pour télécharger les données du jeu publiées par le projet [doduda](https://github.com/dofusdude/doduda) et, pour la version de bureau, ses propres mises à jour. Comme pour tout téléchargement, GitHub reçoit votre adresse IP ; voir la [déclaration de confidentialité de GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
- **Liens.** Les liens sur lesquels vous cliquez (code source, licences) s'ouvrent dans votre navigateur.

Le projet ne collecte et ne traite aucune donnée personnelle : il n'y a donc, de notre côté, aucune donnée à consulter, rectifier ou effacer au sens du RGPD. Pour tout supprimer, désinstallez l'application et supprimez son dossier (`~/Library/Application Support/Dofus Gear Explorer` sur macOS, `%APPDATA%\Dofus Gear Explorer` sur Windows, `~/.config/Dofus Gear Explorer` sur Linux).

Quiconque héberge la version web sur un serveur devient responsable des journaux de ce serveur et doit publier sa propre notice.
